# PRD — نظام محاسبي متكامل عربي

## أصل الطلب
بناء نظام محاسبي عربي كامل يعمل محلياً على Windows، مع فصل كامل بين جهتين: «النقابة العامة» و«مشروع التكافل الاجتماعي»، ويشمل الودائع البنكية، التسويات، الإيرادات، المصروفات، دفتر الأستاذ، القيود اليومية، شجرة الحسابات، ميزان المراجعة، الأصول الثابتة، عضوية مشروع التكافل، استيراد بيانات العضوية، تقارير العضوية، الفاتورة الإلكترونية الداخلية، سجل التدقيق، النسخ الاحتياطي، وإصدار setup.exe عبر NSIS.

## المستخدمون المستهدفون
- أدمن الجهة: يضبط المستخدمين، الخواص، الحسابات، الفترات، النسخ الاحتياطي، والتقارير.
- مستخدم إدخال البيانات: يسجل الإيرادات والمصروفات والودائع والأصول والعضويات ويستورد ملفات العضوية حسب صلاحياته.
- مستخدم المراجعة/العرض: يراجع التقارير والقيود وميزان المراجعة والعضويات والتقارير السنوية.

## المتطلبات الأساسية
- واجهة عربية RTL بالكامل.
- عزل كامل للبيانات حسب `organization_id`.
- مشروع التكافل له صفحة رئيسية بقسمين: الحسابات والعضوية.
- جميع APIs تحت `/api`.
- MongoDB فقط عبر `MONGO_URL` و`DB_NAME`.
- توليد قيود يومية تلقائية متوازنة للعمليات المالية.
- ربط القيود بشجرة الحسابات وظهورها في ميزان المراجعة.
- استيراد بيانات العضوية من الملفات مع تجاهل أي بيانات زائدة غير معتمدة.
- إصدار Windows installer محدث بعد كل تغيير جوهري.

## المعمارية الحالية
- Frontend: React + Tailwind + shadcn/ui، صفحات منفصلة لكل وحدة.
- Backend: FastAPI monolithic في `/app/backend/server.py`، مع Motor/MongoDB وPydantic response models.
- Accounting engine: دوال داخل backend لتوليد قيود يومية تلقائية وربط الحسابات عبر `system_key`.
- Membership engine: حساب سن/تاريخ المعاش تلقائياً، استيراد العضويات، والتقارير السنوية لمشروع التكافل فقط.
- Packaging: NSIS config في `/app/local_install/BankDepositSystem.nsi` يقرأ من `/app/release/BankDepositSystem`.

## وحدة العضوية — تفاصيل التنفيذ
- صفحة العضوية متاحة لمشروع التكافل الاجتماعي فقط.
- بيانات العضو: محافظة، اللجنة النقابية، رقم العضوية، الاسم، الرقم القومي، تاريخ الميلاد، العنوان، ومستلم إعانة الوفاة.
- يمنع تكرار رقم العضوية والرقم القومي داخل الجهة، ويجب أن يكون الرقم القومي 14 رقم.
- البحث بالاسم يعرض صفوف النتائج، وزر عرض يفتح تقريراً منظماً مع طباعة وخروج.
- تصفية خروج المعاش تعتمد على المحافظة/اللجنة والسنة/الشهر فقط، وتعرض مربع عدد الأعضاء خروج معاش.
- حجم العضوية الحالي = إجمالي الأعضاء المسجلين - من خرجوا على المعاش حتى التاريخ الحالي.
- خطة المعاش: قبل يوليو 1971 سن 60، يوليو 1971 سن 61، يوليو 1972 سن 62، يوليو 1973 سن 63، يوليو 1974 سن 64، يوليو 1975 وما بعدها سن 65.

## استيراد العضوية والتقرير السنوي
- الاستيراد يدعم: PDF نصي، Word DOCX، Excel XLSX، وCSV.
- يتم اختيار المحافظة واللجنة قبل الاستيراد، وتطبقان على كل الصفوف المستوردة.
- الحقول المعتمدة فقط: رقم العضوية، الاسم، الرقم القومي، تاريخ الميلاد، العنوان، ومستلم إعانة الوفاة.
- الأعمدة والبيانات الزائدة في الملف لا تحفظ نهائياً.
- الصفوف الناقصة أو المكررة يتم تجاهلها مع سبب واضح.
- التقرير السنوي يعرض: إجمالي المسجل، الداخلين الجدد، الخارجين معاش، وصافي العضوية حسب المحافظة واللجنة، مع الإجمالي.
