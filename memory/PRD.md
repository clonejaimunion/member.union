# PRD — نظام محاسبي متكامل للنقابة العامة ومشروع التكافل الاجتماعي

## بيان المنتج الأصلي
تطبيق محلي يعمل على Windows بنظام واجهة عربية كاملة لإدارة المحاسبة والودائع البنكية لجهتين منفصلتين بالكامل:
- النقابة العامة
- مشروع التكافل الاجتماعي

يجب أن يضمن النظام عزلاً كاملاً للبيانات بين الجهتين، وأن يعتمد على محرك قواعد محاسبية آلي بحيث يُدخل المستخدم أحداث العمل فقط، بينما يقوم النظام بتوليد القيود اليومية المتوازنة وتحديث دفتر الأستاذ دون إدخال يدوي للمدين والدائن. التطبيق موجه للعمل دون إنترنت داخل بيئة Windows محلية مع إمكانية الوصول عبر الشبكة المحلية LAN وحزمة تثبيت NSIS.

## المبادئ الحاكمة
- الواجهة والرسائل والتقارير باللغة العربية وباتجاه RTL.
- لا حذف محاسبي للقيود المرحلة؛ يتم استخدام القيود العكسية للحفاظ على الأثر الرقابي.
- دفتر الأستاذ والميزان والتسويات يجب أن تعتمد على journal_entries كمصدر الحقيقة.
- كل منظمة لها بياناتها ومستخدميها وقواعدها وقيودها بصورة مستقلة.
- محرك القواعد يحوّل الأحداث مثل الإيراد، المصروف، الرصيد الافتتاحي، إذن عضوية جماعي، ربط وديعة، وإهلاك أصل إلى قيود تلقائية متوازنة.
- تقارير PDF وExcel/Word يجب أن تكون عربية قابلة للطباعة والتصدير.

## المعمارية الحالية
- Backend: FastAPI + Motor/MongoDB في `/app/backend/server.py`.
- Frontend: React + Tailwind + Shadcn UI في `/app/frontend/src`.
- قاعدة البيانات: MongoDB عبر `MONGO_URL` و`DB_NAME` فقط.
- التغليف المحلي: NSIS عبر `/app/local_install/BankDepositSystem.nsi`.
- ملفات الإصدار المحلي داخل `/app/release/BankDepositSystem`، وملف التثبيت الناتج `/app/dist/BankDepositSystemSetup.exe`.

## أهم النماذج والكيانات
- `journal_entries`: مصدر الحقيقة للقيود ودفتر الأستاذ.
- `chart_accounts`: دليل الحسابات التلقائي لكل منظمة.
- `accounting_rules`: قواعد الترحيل الآلي.
- `banks` و`bank_settings`: البنوك وأرصدة الإدارة.
- `reconciliations`: التسويات البنكية.
- `memberships`: عضويات مشروع التكافل.
- `membership_batch_payments`: أذون التحصيل الجماعية وتوزيعات FIFO.
- `fixed_assets` و`fixed_asset_depreciations`: الأصول والإهلاكات.

## ما تم تنفيذه سابقاً
- محرك قواعد محاسبية آلي مع محاكاة Fail-Safe.
- دفتر أستاذ وميزان مراجعة من القيود اليومية.
- قيود عكسية بدلاً من حذف القيود المحاسبية.
- سجل تدقيق يتضمن قبل/بعد التعديل.
- تقارير PDF عربية محسّنة.
- إهلاك سنوي تلقائي للأصول الثابتة.
- تحسين تشغيل LAN وملفات التشغيل المحلية.
