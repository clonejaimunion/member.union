# PRD — نظام حساب عوائد الودائع البنكية

## أصل الطلب
المستخدم طلب برنامج عربي احترافي خاص بمعاملات حسابية لفوائد الودائع البنكية، يشبه برامج البنوك، ويشمل: اختيار بنك من ثلاثة بنوك، تسجيل بيانات الوديعة، استخراج تقرير العائد الشهري للسنة الحالية، واستخراج تقرير العائد الشهري للسنة السابقة، مع فصل بيانات كل بنك عن الآخر.

## قرارات المعمارية
- Frontend: React بواجهة عربية RTL، صفحات منفصلة لاختيار البنك، تسجيل الوديعة، تقرير السنة الحالية، وتقرير السنة السابقة.
- Backend: FastAPI endpoints تحت `/api` لإدارة البنوك والودائع والتقارير.
- Database: MongoDB لتخزين الودائع مع فصلها باستخدام `bank_id` لكل بنك.
- الحسابات: الفائدة الشهرية = مبلغ الوديعة × نسبة الفائدة الشهرية ÷ 100، مع احتساب الاستحقاق داخل كل شهر وفق فترة الوديعة.

## المستخدمون المستهدفون
- موظف أو مسؤول مالي يحتاج إدخال بيانات ودائع ومراجعة عوائدها.
- مستخدم يريد فصل تقارير كل بنك عن الآخر بطريقة منظمة وواضحة.

## المتطلبات الأساسية
- صفحة اختيار البنك: بنك التنمية الصناعية، بنك مصر، البنك الزراعي.
- صفحة تسجيل بيانات الوديعة: رقم الحساب، رقم الوديعة، مبلغ الوديعة، تاريخ الإنشاء، تاريخ الاستحقاق، نسبة الفائدة الشهرية.
- صفحة تقرير السنة الحالية: بيانات الوديعة أعلى الجدول + جدول شهري.
- صفحة تقرير السنة السابقة: بيانات الوديعة أعلى الجدول + جدول شهري.
- فصل كامل للبيانات والتقارير بين البنوك.

## ما تم تنفيذه — 2026-04-26
- بناء واجهة عربية احترافية RTL بتصميم بنكي، تنقل علوي، وبطاقات بيانات واضحة.
- تنفيذ API كامل للبنوك والودائع والتقارير مع MongoDB وبدون أي APIs وهمية.
- تنفيذ حساب العائد الشهري للسنة الحالية والسابقة مع جدول 12 شهر وإجمالي العائد.
- إضافة اختبار backend regression suite ونجاح الاختبارات، مع اختبار واجهة عبر Playwright.
- إصلاح تحذير واجهة في قائمة اختيار الوديعة واستبدالها بقائمة مخصصة آمنة.

## إصلاح — 2026-04-26 — حساب العائد الشهري من الفائدة السنوية
- تعديل حساب العائد بحيث يتم التعامل مع النسبة كنسبة فائدة سنوية.
- المعادلة الجديدة: العائد السنوي = مبلغ الوديعة × نسبة الفائدة ÷ 100.
- العائد اليومي = قطع ناتج (العائد السنوي ÷ 365) إلى رقمين عشريين.
- عائد الشهر = العائد اليومي × أيام الشهر المستحقة، بحد أقصى 30 يومًا للشهر الكامل.
- تحقق المثال: 1,000,000 جنيه × 20% = 200,000 سنويًا، اليومي 547.94، شهر 30 يوم = 16,438.20 جنيه.
- تحديث تسميات الواجهة من فائدة شهرية إلى فائدة/عائد سنوي، وإعادة بناء ملف التثبيت.

## إضافة — 2026-04-26 — تقرير فوائد الودائع المستحقة
- إضافة تقرير مستقل باسم "تقرير المستحقات" لكل بنك.
- حساب المستحقات بناءً على يوم ربط الوديعة: آخر صرف شهري يكون في نفس يوم الربط، ثم يتم حساب الأيام المتبقية حتى نهاية السنة المختارة.
- مثال تم اختباره: وديعة مربوطة 18/01/2024 بمبلغ 1,000,000 ونسبة 20%؛ آخر صرف 18/12/2024، الأيام المستحقة 13، العائد اليومي 547.94، المستحق 7,123.22.
- إضافة اختيار السنة من سنة أول وديعة حتى السنة الحالية.
- إضافة زر "طباعة PDF" باستخدام طباعة المتصفح لتصدير التقرير كملف PDF.
- إعادة بناء ملف التثبيت `BankDepositSystemSetup.exe` والتحقق من صلاحيته.

- قسم التسويات البنكية يفتح اختيار البنك الخاص بالتسويات فقط ثم صفحة مذكرة التسوية.
- إضافة زر "القائمة الرئيسية" للرجوع إلى صفحة الاختيارات الرئيسية.
- تعديل عنوان التسوية إلى: "مذكرة تسوية حساب - اسم البنك".
- حذف الجملة التوضيحية الطويلة الخاصة بمعادلة التسوية من واجهة الصفحة.
- إزالة عبارة الترويسة "تسوية بنكية" واستبدالها بعبارة "مذكرة تسوية".
- إعادة بناء ملف التثبيت والتحقق من نجاح الاختبارات.
