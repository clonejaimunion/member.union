# ROADMAP — خارطة طريق النظام

## P0 — المتابعة القريبة
- لا توجد مشكلة وظيفية حرجة في تشغيل localhost/offline بعد اختبار iteration 33.
- إجراء تحقق يدوي على جهاز Windows نظيف بعد تثبيت `setup.exe` مع فصل الإنترنت للتأكد من توفر Python/MongoDB محلياً وتشغيل البرنامج من الاختصار، مع التأكد أن الدخول يتم بدون أي شاشة 2FA.
- لا توجد مشكلة وظيفية حرجة في السوبر أدمن أو إدارة المستخدمين بعد الاختبار؛ فقط CORS في رابط preview العام متبقٍ على طبقة خارجية ولا يؤثر على localhost.
- عند توافر بيانات اعتماد منظومة الضرائب المصرية الفعلية وSDK/أداة التوقيع الرقمي الرسمية، يتم اختبار الإرسال الحي إلى ETA Preprod ثم Production.
- متابعة ملاحظة CORS العامة في preview إذا تغيرت بيئة الاستضافة/ingress.

## P1
- إضافة شاشة سجل نشاط السوبر أدمن تعرض إنشاء/تعطيل/حذف المستخدمين والأدمن بالتفصيل.
- ضبط أدق لتقسيم بنود القوائم المالية بنفس مسميات النماذج الورقية حسب دليل حسابات نهائي من المستخدم.
- إضافة شاشة مراجعة للقيود القديمة التي تم إصلاح ربطها تلقائياً.
- إضافة بيانات اختبار محاسبية سالبة مخصصة لإظهار كل نوع خطأ محاسبي في تقرير واحد للتدريب والمراجعة.
- إضافة تعديل/حذف عضوية من الواجهة مع سجل تدقيق مفصل.
- إضافة تصدير التقرير السنوي للعضوية إلى Excel/Word مباشرة.
- توسيع حماية backend لجميع الوحدات المعطلة من إعدادات الخواص.
- تقسيم `/app/backend/server.py` إلى routers منفصلة لتقليل المخاطر.

## P2
- إضافة مراكز تكلفة وربطها بسطر القيد.
- استيراد/تصدير شجرة الحسابات بصيغ مخصصة مع شعار الجهة.
- تكامل live مع مصلحة الضرائب المصرية عند توفر بيانات الاعتماد والتوقيع الرقمي وبيئة الاختبار.

## اقتراح تحسين
- إضافة سجل تدقيق خاص بالسوبر أدمن يوضح كل عملية إدارة مستخدمين وأدمن مع التاريخ والجهة.
