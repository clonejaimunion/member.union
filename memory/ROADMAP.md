# ROADMAP — خارطة طريق النظام

## P0 — المتابعة القريبة
- لا توجد مشكلة وظيفية حرجة في القوائم المالية السنوية بعد الاختبار.
- متابعة ملاحظة CORS العامة في preview إذا تغيرت بيئة الاستضافة/ingress.

## P1
- ضبط أدق لتقسيم بنود القوائم المالية بنفس مسميات النماذج الورقية حسب دليل حسابات نهائي من المستخدم.
- إضافة بيانات اختبار محاسبية سالبة مخصصة لإظهار كل نوع خطأ محاسبي في تقرير واحد للتدريب والمراجعة.
- إضافة تعديل/حذف عضوية من الواجهة مع سجل تدقيق مفصل.
- إضافة تصدير التقرير السنوي للعضوية إلى Excel/Word مباشرة.
- توسيع حماية backend لجميع الوحدات المعطلة من إعدادات الخواص.
- تقسيم `/app/backend/server.py` إلى routers منفصلة لتقليل المخاطر.

## P2
- إضافة مراكز تكلفة وربطها بسطر القيد.
- استيراد/تصدير شجرة الحسابات بصيغ مخصصة مع شعار الجهة.
- تكامل live مع مصلحة الضرائب المصرية عند توفر بيانات الاعتماد والتوقيع الرقمي وبيئة الاختبار.

## اقتراح تحسين
- إضافة إعداد ربط بنود القوائم المالية بحيث تختار لكل حساب مكان ظهوره في نموذج الميزانية أو الإيرادات أو المقبوضات.
