# ROADMAP — خارطة طريق النظام

## P0 — المتابعة القريبة
- لا توجد مشكلة P0 مفتوحة بعد إصلاح توقف Splash Screen عند 92% وإعادة بناء المثبت واختباره static/API/package في iteration_81.
- إجراء تحقق يدوي نهائي على جهاز Windows فعلي بعد تثبيت `setup.exe` مع فصل الإنترنت للتأكد من سلوك HTA/BAT الصامت، وتشغيل البرنامج من الاختصار، وتوفر Python 3.11 وMongoDB محلياً.
- لا توجد مشكلة وظيفية حرجة في السوبر أدمن أو إدارة المستخدمين بعد الاختبار؛ فقط CORS في رابط preview العام متبقٍ على طبقة خارجية ولا يؤثر على localhost.
- عند توافر بيانات اعتماد منظومة الضرائب المصرية الفعلية وSDK/أداة التوقيع الرقمي الرسمية، يتم اختبار الإرسال الحي إلى ETA Preprod ثم Production.
- تطوير الفيديو الاسترشادي لاحقاً من GIF slideshow إلى MP4 بصوت عربي عند توفير نص التعليق الصوتي أو اختيار محرك صوت محلي/خارجي، مع استخدام نفس محتوى الدليل العربي/الإنجليزي المفصل.
- تحسين حماية ملفات البرنامج لاحقاً بتوقيع رقمي رسمي للمثبّت والملفات التنفيذية عند توفير شهادة Code Signing رسمية.
- تحسين حفظ المسودات لاحقاً بإضافة شاشة استعادة مرئية تعرض آخر مسودة محفوظة بعد إعادة تسجيل الدخول.
- توضيح أوسع لاحقاً داخل الواجهة أن Windows لا يوفر كلمة سر مباشرة للمجلد، وأن القفل الحالي يجمع بين كلمة سر تشغيل + Read-only/ACL؛ التشفير الكامل للمجلد يتطلب EFS/BitLocker أو حاوية مشفرة خارجية.
- إن أراد المستخدم كلمة سر فعلية عند فتح مسار المجلد نفسه من Explorer، فذلك يتطلب دمج أداة Windows Shell/Folder Lock خارجية أو استخدام BitLocker/EFS بسياسة نظام؛ لا يمكن لتطبيق ويب محلي اعتراض فتح مجلد عادي من Explorer بشكل آمن.
- متابعة ملاحظة CORS العامة في preview إذا تغيرت بيئة الاستضافة/ingress.

## P1
- إضافة شاشة سجل نشاط السوبر أدمن تعرض إنشاء/تعطيل/حذف المستخدمين والأدمن بالتفصيل.
- ضبط أدق لتقسيم بنود القوائم المالية بنفس مسميات النماذج الورقية حسب دليل حسابات نهائي من المستخدم.
- تحسين شاشة مراجعة القيود المصححة بإضافة اعتماد/توقيع إلكتروني داخلي قبل الطباعة.
- إضافة بيانات اختبار محاسبية سالبة مخصصة لإظهار كل نوع خطأ محاسبي في تقرير واحد للتدريب والمراجعة.
- إضافة فلاتر متقدمة وجدولة طباعة لتقرير العضوية السنوي بعد تنفيذ التعديل/الحذف والتصدير الأساسي.
- توسيع حماية backend لجميع الوحدات المعطلة من إعدادات الخواص.
- تقسيم `/app/backend/server.py` إلى routers منفصلة لتقليل المخاطر.
